# ChargeFlow

Futuristic offline charging animation app for Android.

The source project is supplied as `ChargeAnimPro.zip`. GitHub Actions extracts it, generates the Gradle wrapper, builds the debug APK, verifies that an APK was produced, and uploads the APK as a workflow artifact.

## Build

Upload `ChargeAnimPro.zip` to the repository root. GitHub Actions will automatically build the debug APK.
